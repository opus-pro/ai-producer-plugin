# AI Producer by OpusClip

Turn a talking-head video into an edit you can keep working on. Tell the agent what you want, and AI Producer cuts the footage, adds captions, reframes the speaker, and builds motion graphics, then hands you an editable preview on the web to refine or export.

## What you can ask for

- Clean up a recording: filler words, false starts, retakes, and long pauses.
- Add captions in a dynamic style, or match the captions of a reference video.
- Add motion graphics, B-roll, sound effects, and background music.
- Change an existing project: "make the captions bigger", "cut the intro", "export it".

## Get started

1. Install AI Producer and start a new conversation.
2. Ask for an edit and attach or point to your video, for example "Edit this interview into a 60-second clip with captions."
3. Sign in to AI Producer when Antigravity asks. The connection uses your OpusClip account.
4. Open the project link the agent gives you to review the edit, adjust it by hand, or export it.

The agent needs to run commands and write files in your workspace, because the edit is authored as files before AI Producer renders it.

## Pricing and limits

Preparing a video and some finishes, such as sound effects or music, can use AI Producer credits. The agent tells you the price before anything is charged. See [AI Producer](https://producer.opus.pro) for plans and upload limits.
