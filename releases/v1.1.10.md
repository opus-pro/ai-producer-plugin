# v1.1.10

## Changes

### Changed

- Author the first effect alone, then up to two effects per continuation while the preceding batch publishes, so the preview fills in progressively without blocking each effect on the previous publication. ([#47](https://github.com/opus-pro/ai-producer-plugin/pull/47))
- The captions skill adds the `files` entries a `build_captions` result now returns, each a path with its sha256, to `expected_files` when a commit names its batch, so the service-staged caption files promote with the round instead of staying staged. ([#46](https://github.com/opus-pro/ai-producer-plugin/pull/46))

## Compatibility

- A commit that names no `expected_files` batch is unchanged. The `files` field is additive on the `build_captions` result; `staged` still lists the same paths.
