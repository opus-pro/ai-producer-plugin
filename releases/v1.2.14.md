# v1.2.14

## Changes

### Added

- Copy a reference's style from a style pack: a reference that was already read, such as a preset, is copied from its caption and motion graphic templates instead of being read and matched again, and an edit keeps a pack for a reference the user brought. ([#145](https://github.com/opus-pro/ai-producer-plugin/pull/145))
- Hold a set of aesthetic rules over every fine cut: real imagery for real things, rhythm floors, a safe area per canvas, readable text, and punch-ins centred on the face. The user's words still take precedence. ([#146](https://github.com/opus-pro/ai-producer-plugin/pull/146))

### Changed

- Fetch a pasted Instagram, TikTok, or YouTube reference link on AI Producer's servers through `start_link_download`. The local downloader and browser sign-in borrowing are removed, each refusal tells the user what to send instead, and a reference longer than the server's limit is refused rather than cut to its first ten minutes. ([#139](https://github.com/opus-pro/ai-producer-plugin/pull/139), [#144](https://github.com/opus-pro/ai-producer-plugin/pull/144), [#147](https://github.com/opus-pro/ai-producer-plugin/pull/147))
- Open the presets view together with the reference question, once the project has started, instead of during the upload. ([#139](https://github.com/opus-pro/ai-producer-plugin/pull/139))
- Place fewer, more deliberate sound effects, with a budget for the whole cut, spacing between sounds, and regular silences. ([#146](https://github.com/opus-pro/ai-producer-plugin/pull/146))
- Show Codex's display name as `AI Producer by OpusClip`, matching Claude Code and Cursor. ([#138](https://github.com/opus-pro/ai-producer-plugin/pull/138))
- Simplify the README's host list, skills overview, and update steps. ([#141](https://github.com/opus-pro/ai-producer-plugin/pull/141))

### Fixed

- Continue an edit after a failed progressive check, upload, or commit by fixing what the refusal names, instead of ending the edit. ([#144](https://github.com/opus-pro/ai-producer-plugin/pull/144))
- Never delete reference working files with a shell wildcard, which made Claude Code stop for approval on every delete. ([#140](https://github.com/opus-pro/ai-producer-plugin/pull/140))

## Compatibility

- Fetching a reference link depends on the service's `start_link_download` tool, which production already serves. No MCP header or capability changes. ([#147](https://github.com/opus-pro/ai-producer-plugin/pull/147))
