# v1.1.11

## Changes

### Fixed

- The local preflight reports `unpromotable_type` before an upload is signed for any workspace file whose type the service never accepts: a script, an `.svg`, or anything outside HTML, CSS, JSON, images, fonts, video and audio. The workspace reference lists the accepted extensions and names the refusal. ([#49](https://github.com/opus-pro/ai-producer-plugin/pull/49))

## Compatibility

- A workspace holding only accepted types checks as before. A local copy of a service-provided script, such as `public/vendor/gsap.min.js`, is declared with `--remote-file` to pass; hidden entries such as `.DS_Store` are ignored.
