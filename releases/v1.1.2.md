# v1.1.2

### Default editorial direction

When a user supplies footage with little creative direction, the plugin previously offered integration rules without a default editorial brief. This release restores six editorial principles in the `aip` skill: opening and pacing, presenter and material framing, media choice, visual hierarchy, semantic emphasis, and motion with optional sound.

The guidance applies during the existing initial planning step, and explicit user requirements take precedence. Stable framing is limited to a continuing explanation, runtime choices preserve meaning, and captions and sound stay conditional. No separate preset read, planning stage, or review loop is added.

The two-skill structure, HF/PIP contract, batch helpers, preview-first delivery, and the no-inspection stopping condition are unchanged.
