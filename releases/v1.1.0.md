# v1.1.0

### Preview-first delivery

A request for a finished talking-head video no longer expands into automatic export, playback inspection, and repeated repairs. The plugin delivers an editable preview link by default, exports only when explicitly requested, and stops without inspecting the generated preview or MP4. Input analysis and local static checks remain available; a concrete admission error permits one targeted resubmission before stopping.

### New in the package

- Bundles the `aip-composition` skill, a focused composition, timing, and editor contract, with a PIP transition reference.
- Adds static helpers `preflight.py` and `upload_batch.py`. Both accept service paths, and hosts without Python 3.10 can use equivalent native tools.
- Removes orphaned export-review instructions. Creative direction remains with the user brief.
