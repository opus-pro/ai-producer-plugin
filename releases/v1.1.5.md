- Add the `aip-captions` skill: the host picks one of the eight subtitle patterns from the video's content and, optionally, the emphasis words, the caption position and placement, the windows where captions hide, and a font pairing; one `build_captions` call has the service build the caption layer and return the element to place in `index.html`. ([#20](https://github.com/opus-pro/ai-producer-plugin/pull/20))

### Fixed

- Add cases to the Codex behavior binding so it is applied where it was missed. ([#25](https://github.com/opus-pro/ai-producer-plugin/pull/25))
