# v1.2.17

## Changes

### Added

- Add the Antigravity plugin package under `antigravity/aip/`, register its manifest and MCP version fields in the release tooling, add strict Antigravity validation in CI, and document local installation. ([#157](https://github.com/opus-pro/ai-producer-plugin/pull/157))
- Add multi-video workflow support in the editing skills and helper scripts, including `source_files.py` preflight checks, multi-source editing-script sync, `place: false` and `transcribe: false` options for later clips, on-demand `start_source_transcript` calls, muted root B-roll clips over the speaker, whole closing-video placement, and workspace digest sync from tool replies. ([#157](https://github.com/opus-pro/ai-producer-plugin/pull/157))
- Add AI Producer Desktop download links to `README.md`. ([#156](https://github.com/opus-pro/ai-producer-plugin/pull/156))

### Changed

- Refine reference-style authoring so a reference's measured style outranks variety-only floors while readability, safe area, contracts, and the 50% showcase floor still come first; add product and brand research before beat planning, whole-pack `## Evidence` checks, and extract detailed graphic, full-cover, and pre-commit rules into `aip-reference-style/references/graphics-rules.md`. ([#160](https://github.com/opus-pro/ai-producer-plugin/pull/160))
- Prefer attribution-free stock libraries first and drop default on-screen source labels, license notices, and credit overlays on sourced B-roll and images unless the speaker explicitly cites a report, study, or dated event. ([#160](https://github.com/opus-pro/ai-producer-plugin/pull/160))
- Update sound-effect placement guidance and split new-project and supporting-visuals guidance into dedicated `new-project.md` and `supporting-visuals.md` references. ([#157](https://github.com/opus-pro/ai-producer-plugin/pull/157))
- Remove remaining Scene restyle and retired `omni-preset` references from skill text. ([#160](https://github.com/opus-pro/ai-producer-plugin/pull/160))

### Fixed

- Prevent filling image slots with stills of the user's own footage, playing the speaker from another moment over their voice, and writing captions over footage that already displays its own captions; wait for the local preview server's bind line before trusting its page. ([#157](https://github.com/opus-pro/ai-producer-plugin/pull/157))
- Normalize `scripts/validate.py` file permissions to `644`. ([#158](https://github.com/opus-pro/ai-producer-plugin/pull/158))

## Compatibility

- All ten version fields across Codex, Claude Code, Cursor, Antigravity, marketplace manifests, and MCP configurations advance to `1.2.17`. Historical commits and reissue sources that predate Antigravity remain accepted by release checks. ([#157](https://github.com/opus-pro/ai-producer-plugin/pull/157))
