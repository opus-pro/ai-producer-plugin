# v1.2.6

## Changes

### Added

- Act on a pasted `@aip` reference line from the Motion library - a motion-asset or omni-preset card - by placing it at its time, with a new handoff reference the entry skill loads when such a line is present. ([#68](https://github.com/opus-pro/ai-producer-plugin/pull/68))
- Keep the running caption on during visual moments: the framing skill places the caption band per layout and canvas, the moment host carries that decision as `data-hide-captions`, `data-caption-position`, and `data-caption-plate`, the dynamic caption skill passes the same windows to `build_captions` as `caption_windows`, and a dark plate backs the caption only where the ground under the band is light. Hiding remains for a headline or statement, dense source text or a photo whose detail must occupy the band, or a brief that asks for silence. ([#73](https://github.com/opus-pro/ai-producer-plugin/pull/73))

### Changed

- Settle the edit with the user before cutting: the entry skill asks three short rounds - rough cut, fine cut, finishes - instead of inferring a whole edit from a bare attachment. Preparation of the project starts first and the rounds are asked while it runs; a round the user's opening already settles is not put to them; each answer is written back to the project, so a resumed conversation reads what is settled. A saved default is confirmed in one card rather than re-asked, and a new set of answers can be kept as the default. The reference image is asked for as its own question. Where the card tools are absent, the same rounds are asked in plain text and nothing is recorded. ([#74](https://github.com/opus-pro/ai-producer-plugin/pull/74))
- Honor an explicit "No captions" answer in the finishes round: the caption layer is not built and its host is left out of the render root, while an existing captioned project keeps its transcript and editor artifacts. Leaving the answer out still means captions are chosen automatically. ([#74](https://github.com/opus-pro/ai-producer-plugin/pull/74))
- Open on a held punch-in with massive text behind the presenter, and show the specific change the speech describes rather than generic shapes. ([#76](https://github.com/opus-pro/ai-producer-plugin/pull/76))

### Fixed

- Point the Codex sign-in step at `codex mcp login ai-producer`, run by the user in their own terminal on the desktop app as much as in the CLI, instead of a connect control on the plugin's page that the desktop app does not have. ([#77](https://github.com/opus-pro/ai-producer-plugin/pull/77))
