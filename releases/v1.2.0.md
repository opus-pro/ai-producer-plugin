# v1.2.0

## Changes

### Changed

- Rename the production MCP connection from `aip` to `ai-producer` so hosts can display the product name in tool activity. Update release validation and progressive tool binding to support the new connection name. ([#55](https://github.com/opus-pro/ai-producer-plugin/pull/55), [#56](https://github.com/opus-pro/ai-producer-plugin/pull/56))

### Fixed

- Keep generated speaker PIP framing and transitions inside their owning visual effect, allowing timeline moves and deletions to apply to the complete treatment without leaving speaker geometry at its old time. ([#57](https://github.com/opus-pro/ai-producer-plugin/pull/57))

## Compatibility

- Update the existing `aip@ai-producer-plugins` installation and start a fresh session. The renamed connection may require signing in again: `codex mcp login ai-producer`, or `/mcp` and `plugin:aip:ai-producer` in Claude Code. The production endpoint and project URLs are unchanged.
- AI Producer Desktop requires a compatible build that accepts the renamed connection before loading this release. Older builds without a valid cached plugin may fail to load the new package.
