# v1.0.0

Initial public release of the OpusClip AI Producer plugin, ready for both Codex and Claude Code.

- Ships the `aip` plugin with both host manifests and both marketplace files.
- Adds the `aip` skill and its workspace reference describing the render-engine workspace contract.
- Configures the remote AIP MCP server.
- MIT license, third-party notices, a security policy, and an offline validation suite (`scripts/test.py`, `scripts/validate.py`).

**Full changelog**: https://github.com/opus-pro/ai-producer-plugin/commits/v1.0.0
