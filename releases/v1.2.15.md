# v1.2.15

## Changes

### Added

- Copy a preset's hook beat by beat: a preset whose style pack carries a hook section maps its opening beats onto the user's opening claim in order, instead of matching the hook again. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))
- Find supporting b-roll as images or video clips from the Web, whichever shows the beat better, from primary sources and open media libraries, never from a platform player. Clips are trimmed and converted to H.264 `.mp4` before staging. ([#151](https://github.com/opus-pro/ai-producer-plugin/pull/151))
- Add a reference on how text treatments are built, and new modes in the reference style helpers: `reference_frames.py --hook-span` and range sampling, and `caption_compare.py page`. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))

### Changed

- A reference graphic copies the reference's look, never what it depicts, and showcase shots are filled from what the user says. Captions no longer play under a graphic that already shows the spoken words. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))
- Keep every project's local files in a working folder of its own, so sessions editing at once do not read each other's files. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))
- Keep local checks inside the project: a page checked on this computer loads the project's own GSAP and is served on a confirmed random port. ([#151](https://github.com/opus-pro/ai-producer-plugin/pull/151))
- In a host with no built-in browser, the reference question links the presets page and lists up to five presets with their ids. ([#149](https://github.com/opus-pro/ai-producer-plugin/pull/149))
- Tell a user who installed only the skills how to add the `ai-producer` MCP server before signing in. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))
- Retire Scene restyle: a preset that needs it now tells the user once that it cannot be applied here. ([#151](https://github.com/opus-pro/ai-producer-plugin/pull/151))

### Fixed

- Hand every edit back through `finish_project`, so the project page leaves its in-progress state and the editor unlocks. ([#150](https://github.com/opus-pro/ai-producer-plugin/pull/150))
- State that no style or template-root attribute can be read off the bound composition root at export, and where to read it instead. ([#151](https://github.com/opus-pro/ai-producer-plugin/pull/151))

## Compatibility

- The service tools these skills call, including `finish_project` and the presets view, are already served in production. No MCP header or capability changes. ([#149](https://github.com/opus-pro/ai-producer-plugin/pull/149), [#150](https://github.com/opus-pro/ai-producer-plugin/pull/150), [#151](https://github.com/opus-pro/ai-producer-plugin/pull/151))
