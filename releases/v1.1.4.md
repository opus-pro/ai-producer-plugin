# v1.1.4

## Changes

### Changed

- Research missing supporting images or clips during planning, inspect sources before authoring, and apply restrained editorial defaults for on-screen text, source readability, visual margins, and graphics. ([#21](https://github.com/opus-pro/ai-producer-plugin/pull/21))
- Simplify the repository homepage with the official logo and product links. ([#14](https://github.com/opus-pro/ai-producer-plugin/pull/14))

### Fixed

- Hand the user the shareable project page URL instead of the agent view. ([#18](https://github.com/opus-pro/ai-producer-plugin/pull/18))

## Compatibility

- The bundled helpers now run on Python 3.9 or newer, lowered from 3.10. Without an interpreter, upload with the host's batch HTTP tools and let admission report contract errors. ([#19](https://github.com/opus-pro/ai-producer-plugin/pull/19))
