# v1.2.16

## Changes

### Added

- Plan the graphic beats before authoring them: a short table of each beat's words, what they are about, its layout family and what it borrows from the reference, checked as text against the layout rules. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))
- Layout variety: no layout family carries more than about a third of an edit's graphic beats, and the family changes at least every 10 s or so. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))
- Start one project from several videos, when the service offers it. The package declares the `multi-video-start` capability; the guide is read only when the service lists more than one video. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))
- Every `commit_workspace` passes an optional `skills_receipt` that tells the service which copy of the skills the edit followed. It changes nothing about the commit. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))

### Changed

- A reference sets the edit's style, the user's content sets each beat's layout. A style pack's motion templates are samples of the reference's look and motion, not layouts to fill, and the reference's timings are a ceiling, not a schedule. A preset's hook keeps its signature graphic and drops beats the user's words cannot carry. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))
- Slimmer skills: conditional passages and host mechanics move into references read only when they apply, so the main skills are about half their former size. ([#153](https://github.com/opus-pro/ai-producer-plugin/pull/153))
- Every host commits the complete graph, then the captions; progressive publication and its scripts are removed. ([#153](https://github.com/opus-pro/ai-producer-plugin/pull/153))
- A 4:5 source keeps a 4:5 canvas. ([#153](https://github.com/opus-pro/ai-producer-plugin/pull/153))

### Fixed

- On a speaker lane that plays more than one file, the local speaker-effects check no longer maps a source second to the cut; the service's commit check stays the authority for those anchors. ([#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))

## Compatibility

- The service still accepts progressive receipts from earlier releases, and ignores `skills_receipt` and the `multi-video-start` capability where it does not serve them. ([#153](https://github.com/opus-pro/ai-producer-plugin/pull/153), [#154](https://github.com/opus-pro/ai-producer-plugin/pull/154))
