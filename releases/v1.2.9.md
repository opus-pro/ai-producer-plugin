# v1.2.9

## Changes

### Added

- Write camera treatments beyond a zoom or filter, such as an impact shake, a white flash, a whip, a push or a handheld drift, as motion hosts: the agent writes each treatment's definition, and the editor lists it as a timeline chip that can be moved, trimmed, deleted, undone and retuned through its declared parameters. Seven worked recipes ship with the composition skill, and the local check runs each definition before upload. ([#103](https://github.com/opus-pro/ai-producer-plugin/pull/103))
- Write a speaker zoom or color filter as an editable effect host instead of a root-timeline tween, so the user can move, trim, delete or retune it, and check every effect host before upload. ([#98](https://github.com/opus-pro/ai-producer-plugin/pull/98))
- Paint code-drawn layers with Canvas 2D, WebGL2 or Three.js in a shape the editor can seek and the export can render, and check them before upload. ([#100](https://github.com/opus-pro/ai-producer-plugin/pull/100))
- Suggest once that a user on an older model switch to the newest one their host offers. ([#94](https://github.com/opus-pro/ai-producer-plugin/pull/94))

### Changed

- Lead the default edit with a creator-style direction: meaningful layout and camera changes, full-screen motion graphics that visualize what the speaker says, and one palette chosen for the topic. The defaults of no background music, a pure black canvas and a fixed order of footage, images and vectors are removed. ([#99](https://github.com/opus-pro/ai-producer-plugin/pull/99))
- Tighten the editing and visuals defaults: supporting visuals are designed as overlays around the presenter, a layout change must name what an overlay cannot carry, an emphasis zoom is at least 1.3x, and the presenter is never shrunk, shifted or split-screened to fit text. ([#96](https://github.com/opus-pro/ai-producer-plugin/pull/96))

### Fixed

- Accept the runtime files the service writes when a document loads them, Three.js and the speaker-effect engine, in a progressive publication receipt, instead of stopping with `publication_receipt_mismatch` after the round was committed. ([#101](https://github.com/opus-pro/ai-producer-plugin/pull/101))

## Compatibility

- Effect hosts, motion hosts and code-drawn layers require the corresponding production service support. Existing plugin and marketplace identifiers remain unchanged.
