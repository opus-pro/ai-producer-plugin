# v1.2.11

## Changes

### Added

- Draw the decision card in Claude Code. A widget loads the pinned card bundle with its caption previews through `show_widget` and names the rounds' components by id, and the rounds are asked with `AskUserQuestion` when no widget tool exists. ([#117](https://github.com/opus-pro/ai-producer-plugin/pull/117), [#118](https://github.com/opus-pro/ai-producer-plugin/pull/118), [#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Show a dark mode icon in the Codex composer and plugin listing. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))

### Changed

- Draw the decision card in the user's language: the card's questions, options and buttons come in English, Chinese, Brazilian Portuguese, Spanish, German, French, Italian, Dutch, Polish or Korean, with caption style names kept as they are. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Ask both rounds, rough cut and finishes, on one decision card with the final card copy. The source upload runs in parallel with the card, so preparation starts as soon as the bytes are in. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Send the "Anything else?" words exactly as typed after the picked list, with no label, and match the light theme field to the design. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- When you change your saved default in a terminal without the card, ask each round again with the saved choice first and marked current, so only what you change moves; without cards, the settling message names each saved choice. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Write the plugin description in English. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Render `scribble-subtitle`, `lead-in-flare` and `tilt-slam` as one centered row on landscape and square canvases. ([#110](https://github.com/opus-pro/ai-producer-plugin/pull/110))
- Say nothing about money when preparing a free project; a preparation that charges is still priced. ([#119](https://github.com/opus-pro/ai-producer-plugin/pull/119))

### Fixed

- Show the corrected Inverted Stack caption preview. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Accept a file already on the service when a commit receipt returns it. ([#126](https://github.com/opus-pro/ai-producer-plugin/pull/126))
- Spell AI Producer in the Codex skill display names, and declare the plugin icon for the Claude directory listing. ([#120](https://github.com/opus-pro/ai-producer-plugin/pull/120), [#123](https://github.com/opus-pro/ai-producer-plugin/pull/123))
