# v1.2.13

## Changes

### Added

- Install and use AI Producer in Cursor Agent, alongside Codex and Claude Code, through a native Cursor plugin manifest and marketplace entry. ([#134](https://github.com/opus-pro/ai-producer-plugin/pull/134))
- Set up AI Producer from ChatGPT with a new setup skill that checks the connection, names the sign-in step for the client in use, and starts from one video and a one-sentence goal. In a ChatGPT Chat conversation, a project now starts from the attached video and editing continues in Work or Codex. ([#133](https://github.com/opus-pro/ai-producer-plugin/pull/133))
- Copy a reference video's style, from a video file, an Instagram, TikTok, or YouTube link, images, a style preset, or a request from the AI Producer web page. The edit follows the reference's captions, motion graphics, and transitions, never its content. ([#136](https://github.com/opus-pro/ai-producer-plugin/pull/136))

### Changed

- Start new projects with fixed settings instead of settings rounds: a balanced rough cut, captions and library sound effects on, and music off. The user's words take precedence over a saved default, which takes precedence over these settings. ([#136](https://github.com/opus-pro/ai-producer-plugin/pull/136))
- Write captions as editable caption moments of static text that the editor can select and retype. ([#136](https://github.com/opus-pro/ai-producer-plugin/pull/136))
- Start a project for a video with no speech or no audio track instead of refusing it, and title it from the user's words or the picture rather than the file name. ([#133](https://github.com/opus-pro/ai-producer-plugin/pull/133))
- State the 30-minute and 3.5 GiB source limits, and load speaker clip pairs only when they play. ([#134](https://github.com/opus-pro/ai-producer-plugin/pull/134))

## Compatibility

- Copying a reference style depends on the service's reference preset capability, which the plugin now declares. ([#136](https://github.com/opus-pro/ai-producer-plugin/pull/136))
