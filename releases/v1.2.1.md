# v1.2.1

## Changes

### Changed

- The user's request is the highest instruction: a listed skill sets a default and its method, an unlisted skill only drops that default, and captions are on by default while the dynamic caption skill is listed. ([#59](https://github.com/opus-pro/ai-producer-plugin/pull/59))
- The `aip-captions` skill is renamed `aip-dynamic-caption`; it picks one of the eight preset caption styles and does not switch captions on or off. ([#59](https://github.com/opus-pro/ai-producer-plugin/pull/59))
- The composition contract states that the caption band is a full-canvas container positioned by the caption build, so a clamped position is corrected with another call rather than a CSS offset on the host or the band. ([#59](https://github.com/opus-pro/ai-producer-plugin/pull/59))
- The progressive publication reference places the caption layer after the last batch, and that caption commit is the one that closes authoring. ([#59](https://github.com/opus-pro/ai-producer-plugin/pull/59))

### Fixed

- Preflight reports the declared, service-built caption composition as a warning instead of an error; every other missing composition stays an error. ([#59](https://github.com/opus-pro/ai-producer-plugin/pull/59))

## Compatibility

- Update the existing `aip@ai-producer-plugins` installation and start a fresh session. A Codex installation that had disabled `aip-captions` returns to the default until the skill is disabled again under its new name; Claude Code cannot disable a single skill within the plugin and always runs the default.
